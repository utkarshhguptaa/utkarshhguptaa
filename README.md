## 🚀 Featured Projects

### [AI Code Review Bot](https://github.com/utkarshhguptaa/code-review-bot)
**Node.js · GitHub Actions · GitHub REST API · Groq (Llama 3.3 70B) · Octokit**

- Reviews pull-request diffs with an LLM and returns structured, severity-ranked feedback.
- Posts inline review comments and handles changed-file paths, multiple comments, and clean-review fallbacks.

### [WorkTruth — Multi-Signal Anomaly Detection](https://github.com/utkarshhguptaa/WorkTruth-Evidence-Platform)
**React · TypeScript · FastAPI · PostgreSQL · NLP · Computer Vision**

- Verifies infrastructure records using cost outliers, semantic duplicates, and reused-image detection.
- Combines signals into explainable risk rankings with a five-stage “Why Trail”.
- Includes CSV ingestion, cross-record analysis, human review, and SMS alerts.

### [Poorvabhas — SIF Precursor Detection](https://github.com/utkarshhguptaa/Poorvabhas)
**Python · FastAPI · PostgreSQL · React · Next.js · spaCy · DistilBERT · XGBoost**

- SIH 2026 project focused on identifying potential serious-injury/fatality precursors in safety reports.
- Uses the EEI Safety Classification and Learning framework and maps reports to IOGP Life-Saving Rules.

### [FemCare AI — PCOS Management System](https://github.com/utkarshhguptaa/FemCare-AI)
**Python · FastAPI · React · PostgreSQL · scikit-learn · SHAP**

- Team project for PCOS-related risk estimation and management support.
- Compared Logistic Regression and Random Forest, with SHAP-based explainability.
- Includes cycle-trend forecasting, variability flags, lifestyle recommendations, and an exportable summary.

### [LeetCode Solutions](https://github.com/utkarshhguptaa/Leetcode)
