## 🚀 Projects

<details open>
<summary><b>🤖 AI Code Review Bot</b> · Node.js · GitHub Actions · Groq / Llama 3.3 · Octokit</summary>

An automated pull-request reviewer that fetches code diffs, asks an LLM to analyze them, and returns structured, severity-ranked feedback.

- Posts inline review comments with useful programming-concept context.
- Handles changed-file paths, multiple comments, and clean-review fallbacks.

[**Open repository →**](https://github.com/utkarshhguptaa/code-review-bot)

</details>

<details>
<summary><b>🧾 WorkTruth — Multi-Signal Anomaly Detection</b> · React · TypeScript · FastAPI · PostgreSQL</summary>

A record-verification platform for identifying potentially suspicious infrastructure records.

- Combines cost outliers, semantic duplicates, and reused-image detection.
- Produces explainable risk rankings with a five-stage “Why Trail”.
- Includes CSV ingestion, cross-record analysis, human review, and SMS alerts.

[**Open repository →**](https://github.com/utkarshhguptaa/WorkTruth-Evidence-Platform)

</details>

<details>
<summary><b>🦺 Poorvabhas — SIF Precursor Detection</b> · Python · FastAPI · React · NLP / ML</summary>

SIH 2026 project focused on identifying potential serious-injury/fatality precursors in safety reports.

- Uses the EEI Safety Classification and Learning framework.
- Maps safety reports to IOGP Life-Saving Rules.

[**Open repository →**](https://github.com/utkarshhguptaa/Poorvabhas)

</details>

<details>
<summary><b>🌸 FemCare AI — PCOS Management System</b> · Python · FastAPI · React · scikit-learn · SHAP</summary>

A team project for PCOS-related risk estimation and management support.

- Compares Logistic Regression and Random Forest with SHAP-based explainability.
- Includes cycle-trend forecasting, variability flags, lifestyle recommendations, and an exportable summary.

[**Open repository →**](https://github.com/utkarshhguptaa/FemCare-AI)
